# MOMOGUM_BE
머머금은 식사 사진과 식당 후기 등의 정보를 인스타그램 스토리처럼 기록하고, 프로필에서 음식통계를 제공하는 SNS입니다.


>이제는 식사모임에서 메뉴를 정할 때 오랜 시간 고민할 필요 없어요! <br>
>내 프로필에 자주 찾는 음식이 정리되어 있으니까요!

## 주요 기능

### 회원기능(담당한 기능⭐️)
- 소셜로그인을 통한 회원가입 및 로그인
- 팔로우, 팔로잉 기능
- 회원 프로필 CRUD

### 밥일기
- 자신이 먹은 식사 공유용 게시글 작성
- 댓글,좋아요 기능
- 밥일기 작성시, 세시간동안 유지되는 스토리 자동 업로드
- 검색기능 (키워드, 제목, 회원)

### 약속잡기
- 팔로우 되어있는 회원 대상으로 약속잡기 기능
